## Maipo Grande Open-Air Market

Description: A web project for Maipo Grande that enables comprehensive management of fruit sales. The platform connects producers, customers, and transporters, facilitating local sales and exports, inventory control, transport auctions, and performance reports.

Objective: To reduce fruit losses, optimize storage and transport, and improve the user experience through a centralized system accessible via web and desktop.

Main Functions:

- Product and inventory management by producers.
- Customer and contract registration and tracking.
- Auctions for transporter selection.
- Administrative control of orders and sales.
- Generation of reports and statistics for consultants and administrators.
- Order and sales status notifications.

## Tech Stack

- **Frontend:** React 18, React Router DOM  
- **State Management:** MobX, mobx-react-lite  
- **UI / Styling:** MUI (Material-UI), Emotion, Sass  
- **Data Visualization:** Recharts, material-react-table  
- **HTTP / Utils:** Axios, Moment, react-number-format, export-to-csv  
- **Testing:** React Testing Library  
- **Monitoring:** web-vitals
